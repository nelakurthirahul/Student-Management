# Student Management System (Java)

A simple Java console-based application to manage student records.
Built for hands-on Java practice and interview preparation.

## Features
- Add student details
- Display all students
- Object-Oriented design
- Uses ArrayList for data storage

## Technologies
- Java
- VS Code

## How to Run
1. Clone the repository
2. Open in VS Code
3. Run `Main.java`
